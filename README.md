# Pintura de partículas

Una pequeña app web interactiva: mueve el ratón (o el dedo) sobre el lienzo y deja un rastro de partículas de colores.

## Cómo usarla

No necesita instalación. Abre el archivo `particulas/index.html` en tu navegador.

## Controles

- **Mover el ratón / dedo**: genera partículas en la posición del cursor.
- **Clic**: lanza una explosión de partículas.
- **Paleta**: cambia entre Neón, Fuego, Océano y Arcoíris.
- **Modo**: cambia el movimiento de las partículas entre Fuente, Órbita y Espiral.
- **Limpiar**: borra el lienzo.
- **Guardar PNG**: descarga tu dibujo como imagen `particulas.png`.

## Tecnologías

HTML, CSS y JavaScript puros con `<canvas>`, en un solo archivo y sin dependencias.
